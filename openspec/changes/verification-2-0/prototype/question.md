# Prototype Question: verification-2-0

## Question

Can one compact, light-only report workspace let a stakeholder understand the
Verification 2.0 release verdict, approved case contract, per-attempt evidence,
and failure-to-repair history without reading raw JSON first?

## Branch

`ui-html`

## Review Target

- Entry: `artifact/index.html`
- Required reviewer decision: approve or reject the shared three-page
  information architecture, state vocabulary, evidence density, and mobile
  behavior before production report implementation.

## Out of Scope

- Production report renderer implementation.
- Real test execution or evidence mutation.
- Managed runtime installation.
- Dark mode or runtime language switching.
- Release, deployment, or archive action.
